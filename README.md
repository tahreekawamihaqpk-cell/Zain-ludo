

# Zain Ludo 🎲

A Ludo game project by Zahid Mandan.

## Planned Features

- Four-player Ludo: Red, Yellow, Green, and Blue.
- Red and Green positions swapped.
- 20-second turn timer.
- Roll again when a six is rolled.
- Token movement, captures, safe squares, and home.
- Automatic turn handling.
- Online multiplayer with friends and room codes.
- Voice chat.
- Bluetooth play where supported.
- Master Class and tournaments.
- Coins, diamonds, invitations, and player chat.

## Development Status

This project is under development. Online multiplayer, voice chat, and Bluetooth features require additional implementation and testing.
